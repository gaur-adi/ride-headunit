# Sharing Ride Headunit

These are drafts for the maintainer to review and post where community rules allow. No community posts have been sent automatically.

## Short introduction

I adapted Open Headunit into a bike-focused Android Auto receiver called Ride Headunit. It turns a spare ARM64 Android phone into a wireless display for a main Android phone, with a dark dashboard, 720p/30 FPS and compatibility profiles, and portrait/landscape support that follows the system Auto-rotate toggle. With Auto-rotate off, it uses landscape.

Tested on a OnePlus 10T running Android 15. Native wireless mode does not require Developer options on the main phone. It is a preview build and compatibility varies by device. It does not add Google Maps motorcycle routing to Android Auto.

Source and APK: https://github.com/gaur-adi/ride-unit
Setup: https://gaur-adi.github.io/ride-unit/
Upstream: https://github.com/andreknieriem/open-headunit

Feedback on receiver compatibility, reconnection and portrait layouts is welcome. Upstream attribution and AGPL-3.0 licensing are retained.

## Demonstration checklist

Use a parked test setup. Do not display personal notifications, exact location, home address, contacts, credentials or license plates.

1. Show the Ride Headunit dashboard and profile selector.
2. Show Android Auto connecting and opening a map without personal location details.
3. Turn the receiver upright and hold it steady; show the brief reconnect and portrait map.
4. Disable system Auto-rotate and show the landscape default.
5. End with the repository link, tested-device details and motorcycle-routing limitation.
